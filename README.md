This tool was developed to scan the web pages source code and run through each element to check for any DOM XSS payloads and remove them or sanitise them. This web extension works on Firefox based web browsers. The extension is resource intensive and may break web pages. This web extension is to be used as an unpacked or temprarily loaded extension. To use it click on the manifest.json file when loading the extension. The extension does not work on Microsoft edge, Chrome and Brave. The extension works on browsers that support mainfest version 2 extensions.

**How it works**
The extension works by checking the web page for vulnerable code in the web page. It bundles up the vulnerable pieces of code, checks each of them and assigns a classifcation value to each vulnerable picece of code whether it is safe, unrecongnised or dangerous.
